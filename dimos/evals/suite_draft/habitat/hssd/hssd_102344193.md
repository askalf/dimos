## Scoring and validation

`E(x)=exact(x, answer.strip().upper())`; `Y(x)=exact(x, yes_no(answer))`; `C(n)=exact(n, first_number(answer))`; `N(r,t,b)=numeric(r, first_number(answer), tolerance=t, band=b)`; `R(s)=rank_order(s, ranking(answer))`. Numerical scores are 1 inside ±t and decrease linearly to zero at ±b. Ranking earns the correctly ordered pair fraction; invalid permutations score zero. Parser failures score zero. Bands are proposed, not validated sensor precision.

Do not expose metadata/reference answers to the evaluated agent. The `washer/dryer` category incorrectly includes an asset named `DISHWASHER HOBART`; the suite uses product names and location to distinguish it. User approval covers the question set; no complete agent episode has been run for this suite.
